🚀 HOW TO USE IMMEDIATELY

  1. Ensure servers are running:
     Terminal 1: cd backend && node server.js
     Terminal 2: cd frontend && npm run dev

  2. Open browser: http://localhost:5174

  3. Upload YASH file:
     - Click "Upload Price List"
     - Select: YASH_Automobiles_PriceList.xlsx
     - Click "Upload File"

  4. View price table:
     - See all 10 columns with 33 vehicles
     - Scroll horizontally and vertically
     - Model names highlighted in blue

  5. Generate quotation:
     - Enter customer name
     - Type vehicle name (autocomplete suggests)
     - Add quantity
     - Add multiple vehicles
     - Set tax and discount
     - Click "Generate Quotation"

  6. Print/Save:
     - Click "📄 Print / Save as PDF"
     - Choose print or save as PDF

🔧 CUSTOMIZATION

  To Change Price Column:
    1. Edit: /backend/quotationService.js
    2. Find: const unitPrice = parseFloat(vehicle['ON ROAD'])
    3. Change to: const unitPrice = parseFloat(vehicle['ON ROAD WITH ASSY.'])
    4. Or use any other column: EX S/R, RTO, INSU, etc.

  To Add More Vehicles:
    1. Open: YASH_Automobiles_PriceList.xlsx
    2. Add new rows with vehicle data
    3. Keep MODEL column consistent
    4. Save and upload through app
    5. All new vehicles instantly available

  To Create Your Own Format:
    1. Create Excel file with MODEL column
    2. Add any other columns you need
    3. Upload through app
    4. All columns displayed automatically
