🔍 EXCEL FORMAT DETAILS

Column Structure:
  MODEL                          ← Primary key (vehicle name)
  EX S/R                         ← Ex-Showroom Rate
  RTO                            ← Road Tax
  INSU                           ← Insurance
  INCIDENTAL & ADMIN CHARGES     ← Admin charges
  HELMET                         ← Helmet cost
  ON ROAD                        ← On-road price (used in quotations)
  GL                             ← Glass/Other
  STD ASSY KIT                   ← Assembly kit cost
  ON ROAD WITH ASSY.             ← On-road with assembly

All columns optional except MODEL
All numeric columns auto-formatted with commas

💡 CUSTOMIZATION TIPS

To Change Price Column for Quotations:
  File: /backend/quotationService.js (Line ~26)
  Find: const unitPrice = parseFloat(vehicle['ON ROAD']) || 0;
  Change 'ON ROAD' to any column name:
    - 'EX S/R' for Ex-Showroom Rate
    - 'ON ROAD WITH ASSY.' for assembled price
    - Any custom column name

To Add More Vehicles:
  1. Open: YASH_Automobiles_PriceList.xlsx
  2. Add new rows at bottom
  3. Fill all columns
  4. Save file
  5. Upload again through app
  6. New vehicles instantly available

To Create Custom Format:
  1. Create Excel with MODEL column (required)
  2. Add any other columns needed
  3. Save as .xlsx
  4. Upload through app
  5. All columns auto-displayed
