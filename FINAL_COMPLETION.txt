⚡ HOW TO USE NOW

1. Open Browser
   → Visit: http://localhost:5174

2. Upload Price List
   → Click: "Upload Price List"
   → Select: YASH_Automobiles_PriceList.xlsx
   → Click: "Upload File"
   → Result: All 33 vehicles displayed in table

3. View Price Table
   → See all 10 columns with all 33 vehicles
   → Scroll horizontally for all columns
   → Scroll vertically for all vehicles
   → Model names shown in blue with formatting

4. Generate Quotation
   → Enter customer name
   → Type vehicle model (autocomplete suggests)
   → Enter quantity
   → Add more vehicles (optional)
   → Set tax rate (default 5%)
   → Set discount (optional)
   → Click: "Generate Quotation"

5. View & Print Quotation
   → Professional quotation modal displays
   → All calculations shown
   → Click: "📄 Print / Save as PDF"
   → Print or save from browser
